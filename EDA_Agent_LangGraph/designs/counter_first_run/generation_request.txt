创建用于真实 VCS 仿真的 8 位无符号计数器演示工程。仅生成两个文件 rtl/counter_8bit.v 和 tb/tb_counter_8bit.v，不生成其他文件。DUT 顶层 counter_8bit，端口 clk,rst_n,en,count[7:0]；posedge clk 计数，rst_n 为异步低有效复位，en=0 保持，en=1 加一，255 回绕到0。测试平台顶层 tb_counter_8bit，使用 Verilog 或 VCS 2014 支持的 SystemVerilog，自动生成10ns周期时钟，驱动输入在下降沿改变，采样在上升沿后1ns进行，用独立参考模型自动比对，不从DUT输出计算期望值。覆盖初始复位、保持、连续至少300次加一以覆盖回绕、运行中异步复位和至少500次固定种子随机使能；异步复位必须在非时钟上升沿施加并在时钟边沿前检查清零。成功检查打印 [PASS]，真实失配打印 [FAIL] 并增加failed。结束输出 total checks = N, passed = M, failed = K 和 scenarios: 场景列表；全部通过时输出 TEST PASSED，否则 TEST FAILED。设置独立仿真超时以免卡住。禁止在未仿真前宣称通过。两个文件总长度尽量不超过220行。
