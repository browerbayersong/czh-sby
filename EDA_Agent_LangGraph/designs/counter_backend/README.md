## 实验顺序

1. 核对同一工艺库的逻辑库、物理参考库、技术文件、寄生参数与层映射。
2. DC：导入 RTL 和约束，综合并导出网表、SDC、DDC、面积、时序和功耗报告。
3. ICC：导入对应网表，完成 floorplan、placement、时钟树和 routing，保存数据库、布局布线结果、布线 DRC 和连通性检查。
4. PT：读取后端网表、约束和寄生参数，输出时序与功耗报告，记录实际活动标注范围。
5. 保存真实 GUI/工具输出截图，校验日志与指标后更新 Word 报告。

功耗需要明确时钟、库角与活动假设；若使用仿真活动，保存原始 VCD/SAIF 和标注报告。ICC 布线检查与晶圆厂完整签核 DRC 分开标注，未完成的检查不能写成通过。

`environment_checks/` 保存初次环境检查，`session_queue/` 保存此次持续 SSH 会话的任务与结果。密码仅保留在本机运行进程的内存中，不写入上述文件。
