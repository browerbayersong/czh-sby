## 二、编译配置

在聊天工作空间根目录放 `compile_cfg.json`，不放在则退回自动扫描：

```json
{
  "filelist": ["files.f"],
  "defines": {"WIDTH": "8", "SIM": ""},
  "incdirs": ["generated/rtl/inc"],
  "tb_top": "tb_fifo_sync",
  "options": ["+lint=all"]
}
```

| 字段 | 等价 VCS 参数 |
| --- | --- |
| `filelist` | 源文件列表；`.f` 在本地展开（支持 `+incdir+`、`+define+`、`//`/`#` 注释） |
| `defines` | `+define+KEY=VALUE` |
| `incdirs` | `+incdir+...` |
| `tb_top` | `-top`（覆盖网页输入） |
| `options` | 白名单：`-sverilog`、`+v2k`、`-timescale=1ns/1ps`、`+lint=all`、`+lint=context` |

安全规则：

* 所有路径必须是工作空间内的相对路径，禁止绝对路径、`..` 与符号链接；
* `.f` 只做本地解析、不上传，其中列出的源码必须已在上传列表；
* 未识别字段或非白名单选项直接报错，不静默忽略。

## 三、运行历史页

「📜 运行历史」按轮次查看：

| 区块 | 内容 |
| --- | --- |
| 指标 | 状态、编译/仿真退出码、覆盖率、源文件数 |
| 源文件 | 本轮实际参与编译的文件与顺序 |
| 编译配置 | 用了 `compile_cfg.json` 还是自动扫描（含 defines） |
| 快照哈希 | 从 `snapshot_manifest.json` 读取的逐文件 SHA-256 |
| 错误摘要 | 失败轮抽取 `[FAIL]` / `Error-` 行 |
| 日志 | 编译、仿真日志下载 |

`remote_job` 现在会把 `snapshot_manifest.json` 同时写入本地 `remote_runs/<run_id>/`，
历史页无需联网即可显示哈希；早期轮次已回填 6 轮。

## 四、验收

```powershell
.\venv\Scripts\python.exe verify_p2.py
```

10 项自动判定，全 PASS 才返回 0；输出同时写入 `docs/P2_验收结果.txt`。

| 检查项 | 判定方式 |
| --- | --- |
| 五套离线测试 | 子进程退出码为 0 |
| 工具路径配置化 | 设置 `EDA_VCS_BIN` 后导入模块并断言 |
| 运行历史 SHA-256 | 带 `snapshot_manifest.json` 的轮次 ≥ 3 |
| 历史详情可读 | `load_run_detail` 能读出状态、清单与日志 |
| 前端缓解 | 源码存在 `st.fragment(_log_viewer)` 且带回退 |
| 换工程可用 | `evidence/` 下 FIFO / 加法器 / 计数器均有 `passed_by_marker` |

## 五、已知限制

1. `removeChild` 是 Streamlit 前端渲染问题，本次只缩小触发面，未根治；
2. `.f` 暂不支持 `-y`、`+libext`、`-v` 等指令，遇到会直接报错；
3. `options` 是白名单，新增选项需改代码并补测试；
4. 历史页只读本地 `remote_runs/`，不主动连虚拟机拉取。
